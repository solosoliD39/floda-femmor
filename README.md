# Floda Femmor

Uppställningsverktyg för Floda IBK herr 4: närvaro, femmor som fylls utifrån en gemensam optimal uppställning, och delning via länkar i WhatsApp.

Appen: https://solosolid39.github.io/floda-femmor/

Inga spelardata ligger i koden. Truppen och uppställningarna följer med i länkarna och sparas i webbläsaren hos den som öppnar dem.
